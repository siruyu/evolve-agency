## Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS 4 + PostCSS
- **Animation:** Motion
- **Typography:** Inter
- **Tooling:** ESLint, Autoprefixer

## Getting Started

```bash
npm install
npm run dev      # local development
npm run build    # production build
npm run start    # start production server
```
